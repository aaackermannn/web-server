# Real-time Chat Server на Go

Высокопроизводительный веб-сервер для обмена сообщениями в реальном времени с поддержкой комнат чата, списком пользователей и уведомлениями.

## 🚀 Возможности

### Основной функционал
- **WebSocket соединения** с авторизацией по имени пользователя
- **Управление комнатами** - автоматическое создание/удаление комнат
- **Обмен сообщениями** в реальном времени с форматированием JSON
- **Управление пользователями** с уведомлениями о входе/выходе
- **Временные метки** сообщений и ограничение длины (500 символов)

### Веб-интерфейс
- **Адаптивный дизайн** для всех устройств
- **Страница подключения** с выбором комнаты
- **Интерфейс чата** с историей сообщений
- **Список онлайн пользователей** в комнате
- **Индикатор статуса соединения**
- **Автоматическое переподключение**

### Безопасность и производительность
- **Валидация входных данных** с защитой от XSS
- **Rate limiting** для предотвращения спама
- **CORS поддержка** для кросс-доменных запросов
- **Заголовки безопасности** для защиты от атак
- **Оптимизированное использование памяти** и горутин

## 📋 Требования

- Go 1.21 или выше
- Docker (опционально)

## 🛠 Установка и запуск

### Локальная разработка

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd web-server
   ```

2. **Установка зависимостей**
   ```bash
   make deps
   # или
   go mod tidy
   ```

3. **Запуск приложения**
   ```bash
   make run
   # или
   go run main.go
   ```

4. **Открытие в браузере**
   ```
   http://localhost:8080
   ```

### Сборка для продакшена

```bash
# Сборка приложения
make build

# Запуск собранного приложения
./build/chat-server
```

### Docker

```bash
# Сборка Docker образа
docker build -t chat-server .

# Запуск с Docker Compose
docker-compose up -d

# Просмотр логов
docker-compose logs -f
```

        └── app.js        # JavaScript

### Компоненты системы

1. **Room Manager** - управление комнатами чата
2. **User Manager** - управление пользователями и их сессиями
3. **Message Handler** - обработка и валидация сообщений
4. **WebSocket Handler** - управление WebSocket соединениями
5. **HTTP Handlers** - REST API для получения информации о комнатах

## 🔧 API

### WebSocket Endpoints

- `ws://localhost:8080/ws?username=<имя>&room=<комната>`
  - Подключение к чату с указанием имени пользователя и комнаты

### HTTP Endpoints

- `GET /` - Главная страница чата
- `GET /api/rooms` - Получение списка доступных комнат
- `GET /static/*` - Статические файлы

### WebSocket Messages

#### Отправка сообщения
```json
{
  "content": "Текст сообщения",
  "roomId": "название-комнаты"
}
```

#### Получение сообщения
```json
{
  "type": "message",
  "data": {
    "id": "uuid",
    "userId": "user-uuid",
    "username": "Имя пользователя",
    "content": "Текст сообщения",
    "roomId": "название-комнаты",
    "timestamp": "2024-01-01T12:00:00Z",
    "type": "message"
  }
}
```

#### История сообщений
```json
{
  "type": "history",
  "data": {
    "messages": [...],
    "users": [...]
  }
}
```

## ⚙️ Конфигурация

Настройки можно изменить через переменные окружения:

- `PORT` - порт сервера (по умолчанию: 8080)
- `MAX_MESSAGE_LENGTH` - максимальная длина сообщения (по умолчанию: 500)
- `MAX_USERNAME_LENGTH` - максимальная длина имени пользователя (по умолчанию: 20)
- `MAX_ROOM_NAME_LENGTH` - максимальная длина названия комнаты (по умолчанию: 30)
